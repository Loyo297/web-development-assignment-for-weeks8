# SpendWise

SpendWise is a responsive, browser-based personal finance dashboard built with plain HTML, CSS, and JavaScript. It gives you a quick view of your balance, monthly income and expenses, weekly spending, and a simple monthly budget.

## Run it

Open `index.html` in a browser. For a live-reloading local preview, open the project folder in VS Code and use **Open with Live Server** if that extension is installed. No build step or package installation is required.

## Use the dashboard

- Add an income or expense from the **Quick add** form.
- Search transactions, or filter the list to show income or expenses.
- Remove a transaction with the × button beside it.
- Use the ↻ button in the header to restore the sample transactions.
- The dashboard saves changes in your browser using local storage. The sample account is for demonstration; this is not connected to a bank.

The budget limit is set to $2,400 per month in `script.js`. Amounts are displayed in US dollars.

## Project files

- `index.html` — dashboard layout and form
- `style.css` — responsive visual design
- `script.js` — transaction handling, summaries, chart, filters, and local storage
- `README.md` — setup and usage notes
